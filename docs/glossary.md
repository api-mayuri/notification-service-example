# Единый язык ограниченного контекста «Нотификации»

| Термин | Класс | Значение |
|---|---|---|
| Уведомление | `Notification` | Принятый запрос: кому, что и по каким каналам отправить. Агрегат |
| Отправитель (клиент) | `ClientId` | Система, запросившая уведомление: `client_id` из JWT или `ce_source` из Kafka |
| Получатель | `RecipientId`, `Recipient` | Пользователь во внешней системе; контакты передаются в запросе или берутся из сервиса пользователей |
| Контакт | `ContactType`, `RecipientContacts` | Сырое значение: email, phone, telegramChatId, deviceToken, webhookUrl |
| Канал | `ChannelType` | Способ доставки: EMAIL, SMS, TELEGRAM, WHATSAPP, PUSH, WEBHOOK. Набор открытый |
| Адрес | `ChannelAddress` (`EmailAddress`, `PhoneNumber`, …) | Проверенный контакт конкретного канала |
| Доставка | `Delivery` | Отправка одного уведомления по одному каналу со своей машиной состояний. Агрегат |
| Попытка | `Delivery.attempts` | Один вызов провайдера. Попытки считает домен |
| Провайдер | `EmailProvider`, `SmsProvider`, … | Конкретный инструмент канала (SMTP, SMS-шлюз, Bot API, FCM) |
| Отправитель канала | `ChannelSender` | Адаптер канала: проверяет адрес, вызывает провайдера, возвращает `SendResult` |
| Заглушка | `Logging*Provider` | Провайдер, который пишет в лог и возвращает успех с `simulated=true` |
| Временная ошибка | `SendResult.RetryableFailure` | Повторяется по политике повторов: сеть, 4xx SMTP, 5xx/429 HTTP |
| Постоянная ошибка | `SendResult.PermanentFailure` | Не повторяется: неверный адрес, заблокированный бот, 5xx SMTP |
| Политика повторов | `RetryPolicy` | Экспоненциальный backoff с jitter и максимум попыток |
| Parking lot | DLT `…-dlt` | Топик для доставок, которые не удалось отправить; разбирается вручную |
| Шаблон | `Template` | Ключ + канал + локаль; содержит версии. Агрегат |
| Версия шаблона | `TemplateRevision`, `TemplateVersion` | Неизменяемое содержимое: тема, тело, обязательные переменные. Статус DRAFT, ACTIVE или ARCHIVED |
| Локаль | `LocaleTag` | Тег BCP 47. Fallback: `ru-KZ → ru → локаль по умолчанию` |
| Отрендеренное сообщение | `RenderedMessage` | Готовые тема и тела плюс ключ, версия и локаль шаблона |
| Готовое содержимое | `RawContent` | Текст без шаблона; только для доверенных отправителей |
| Категория | `Category` | TRANSACTIONAL, SYSTEM (обязательные) или MARKETING (можно отписаться, учитывает тихие часы) |
| Приоритет | `Priority` | LOW, NORMAL, HIGH. HIGH обрабатывается в отдельной полосе |
| Предпочтения | `RecipientPreferences` | Отписки, тихие часы, часовой пояс (IANA), язык. Агрегат |
| Тихие часы | `QuietHours` | Интервал местного времени, когда MARKETING не отправляется, а откладывается |
| Отписка | — | Отказ от канала или категории; не действует на обязательные категории |
| Пропущенная доставка | `DeliveryStatus.SKIPPED`, `SkipReason` | Доставка не выполнялась: отписка или нет контакта |
| Отложенная отправка | `sendAt` | Доставка ждёт в БД, планировщик ставит её в очередь в срок |
| Постановка в очередь | `DeliveryDispatcher` | Публикация доставки в топик канала через outbox |
| Ключ идемпотентности | `IdempotencyKey` | Уникален в паре с отправителем; повтор возвращает исходный результат |
| Отпечаток запроса | `CommandFingerprint` | SHA-256 тела запроса; другой отпечаток при том же ключе — конфликт |
| Дедупликация | `DeduplicationKey` | Схлопывание одинаковых уведомлений одному получателю в окне шаблона |
| Лимит частоты | `RateLimit` | Не больше N отправок получателю по каналу за окно; сверх лимита — отложить |
| Outbox | Event Publication Registry | Таблица `event_publication`: сообщения сохраняются в транзакции и отправляются в Kafka после коммита |
| Внешнее сообщение | `ExternalMessage` | CloudEvent для Kafka: топик, ключ, атрибуты, JSON |
| Статус уведомления | `NotificationStatus` | ACCEPTED, IN_PROGRESS, COMPLETED, PARTIALLY_FAILED, FAILED, CANCELLED — вычисляется из доставок |
| Зависшая доставка | — | В SENDING дольше порога (экземпляр упал); планировщик возвращает её в очередь |
