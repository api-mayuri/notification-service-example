# Рабочие материалы ИИ-агента

Эта папка — контекст для ИИ-ассистентов (Claude Code и др.), которые дорабатывают сервис. Разработчикам она не нужна: документация для людей — в [README](../README.md) и [docs/](../docs).

| Файл | Что внутри |
|---|---|
| [progress.md](progress.md) | журнал сессий: что сделано, что проверено, исправленные баги, открытые вопросы |
| [plan.md](plan.md) | исходный план: модули, пакеты, схема БД и брокера |
| [research.md](research.md) | исследование перед разработкой: что взято из примеров и почему |

Инструкции для агента — [CLAUDE.md](../CLAUDE.md) в корне репозитория.
